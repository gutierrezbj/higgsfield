# Higgsfield · centro de producción JRGB

Método, guías, plantillas y skills para producir imagen y vídeo con IA en Higgsfield (cortos, series y anuncios para clientes).

## Dónde vive cada cosa
| Qué | Dónde |
|---|---|
| Texto: método, guías, skills, plantillas | **Este repo** (copia del Project "Higgsfield" de claude.ai) |
| Material pesado: PDF, imágenes, vídeos, entregas | Google Drive · [Higgsfield](https://drive.google.com/drive/folders/1lgs-_HykJb3aS_wImMDzn97dqfMbju5P) |
| Chats de producción | Project "Higgsfield" en claude.ai |

## Estructura
```
00-Infraestructura.md        dónde vive cada cosa y estructura de Drive
academy/                     curso Higgsfield Academy "Creación con IA: primeros pasos"
  tareas/L01…L06/            tareas de JuanCho en el curso (notas, prompts, planes)
  00-LEEME-Academy.md        índice y arranque
  01-Leccion-por-leccion.md  método de cada lección
  02-Entregables.md          qué se puede producir y con qué
  03-Guias-PDF-L4-L5.md      guías de recursos, planos y cámara
  Academy-L4-Biblioteca-prompts.md   26 prompts de imagen
  skills/                    CINEIMAGE, Seedance Prompter (cinedance-lite), UGC Video Creator
Higgsfield ADS/              anuncios para clientes (método "Animals" de Adil)
  skills/                    acting skill, Seedance prompt (Blockbuster)
  SOP-01-Campana-de-producto-IA.md   SOP de campaña de producto
metodo/                      métodos de Adil (cortometrajes, ahorro de créditos) y MAPA-Higgsfield
proyectos/                   un subproyecto por corto o serie (ULTRAFAST, HUELLAS, Persecucion-Caracas)
conector/                    flujos de trabajo del conector de Higgsfield en Claude
.claude/skills/              enlaces a las 5 skills para que Claude Code las cargue solas
```

## Usarlo en otra máquina
```bash
git clone https://github.com/gutierrezbj/higgsfield.git

claude
```
