## Aprendizajes para el SOP (25-10)
- Método antes que herramienta: el paso es "fijar el activo" (producto, creador, localización); el modelo es intercambiable.
- Pedir el modelo por su nombre cuando importa el coste: Character Sheet sin indicar modelo = 2,5 cr por hoja; con Soul 2.0 = 0,125.
- Soul (y Soul Cinema) para explorar opciones baratas; Seedream / Nano Banana para conservar una cara o un producto real.
- Comparar precios antes de aplicar la regla del borrador: si 1K y 2K cuestan igual, 2K.
- Criterios de localización: encaja con producto y público · el producto contrasta · espacio para la acción · luz coherente · limpia (sin gente, textos ni logos) · varias opciones y rondas con un cambio.
- "Luz suave y natural" sale plana; para que no quede sosa, pedir hora dorada y colores vivos desde el principio.
- La ficha de producto incluye sus comportamientos conocidos (p. ej. el cristal cambia de color con el sol).
- Las skills (.md) son prompts convertidos en producto: la biblioteca de recursos son skills propias por trabajo.
- Acento: describir la fonética (seseo, s aspirada, ritmo, entonación) y listar los acentos que NO se quieren; nombrarlo solo no basta.
- Cambiar la ropa sin rehacer la hoja funcionó con "same woman, same hair, same body, changed clothing only". Aun así, lo limpio para el SOP es fijar el vestuario en la hoja.
- Si el agente adapta el texto exacto, debe avisar y pedir validación (lo hizo bien).
